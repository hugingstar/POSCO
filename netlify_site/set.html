집합 (Set)

기본 개념

집합은 순서가 없고 중복을 허용하지 않는 고유한 데이터들의 모음입니다. 중괄호 {}를 사용하거나 set() 생성자를 통해 만듭니다.

AI 모델 및 자동화에서 사용하는 이유

  • 초고속 중복 제거: 데이터 전처리 시 수만 건의 데이터셋에서 중복된 URL, 아이디, 텍스트 등을 단 한 줄의 코드로 가장 빠르고 완벽하게 걸러낼 수 있습니다.
  • 빠른 검색 (O(1) 속도): 내부적으로 해시 테이블을 사용하므로, 특정 단어 나 데이터가 존재하는지 검사할 때 리스트보다 압도적으로 빠릅니다. (자연어 처리(NLP)에서 단어 사전 구성 시 핵심 기술)
  • 데이터 교차 검증: 두 개의 다른 데이터셋 간의 교집합(공통점)이나 차집합(누락된 부분)을 찾아내는 수학적 연산을 지원하여 로직을 매우 간결하게 만듭니다.
