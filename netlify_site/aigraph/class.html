🦜 파이썬 클래스 (Class)

클래스 구조 (Class Structure)

"자주 사용하는 변수들과 함수(메소드)들을 하나의 커다란 설계도(틀)로 묶어놓은 것을 클래스라고 해무새! 흔히 붕어빵 틀에 비유하지 껄껄."

  • 클래스(Class): 붕어빵 틀 (설계도)
  • 객체/인스턴스(Object): 틀에서 찍어낸 실제 붕어빵 (결과물)

메소드 (Methods)와 생성자 (__init__)

클래스 안에 들어있는 함수를 메소드라고 불러! 클래스가 만들어질 때 가장 먼저 자동으로 실행되는 특별한 메소드가 바로 생성자(__init__)야.

  • self: 자기 자신을 가리키는 파라미터야. 클래스 내부의 변수나 다른 메소드를 부를 때 꼭 붙여줘야 해!
class Bird:
    def __init__(self, name: str):
        # 생성자: 새가 태어날 때 이름을 정해준다무새
        self.name = name

    def speak(self) -> None:
        # 일반 메소드
        print(f"{self.name}가 짹짹 운다!")

# 클래스로 객체 만들기
my_bird = Bird("참새")
my_bird.speak() # 참새가 짹짹 운다!

상속 (Inheritance)

이미 만들어둔 붕어빵 틀(부모 클래스)의 모든 기능을 그대로 물려받고, 거기에 새로운 기능만 살짝 추가해서 새로운 틀(자식 클래스)을 만드는 마법이야!

# Bird 클래스를 상속받는 껄무새 클래스 만들기
class Parrot(Bird):
    def mimic(self, word: str) -> None:
        # 부모(Bird)에 없던 새로운 메소드 추가!
        print(f"{self.name}가 사람 말을 따라한다: '{word}' 껄껄!")

# 객체 만들기
my_parrot = Parrot("껄무새")
my_parrot.speak() # 부모 클래스의 기능을 그대로 사용!
my_parrot.mimic("파이썬 최고") # 자신만의 기능도 사용!
