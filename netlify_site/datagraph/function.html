🦜 파이썬 함수 (Function)

기본 개념

"함수는 자주 쓰는 코드를 하나의 상자에 담아두고 필요할 때마다 꺼내 쓰는 마법 같은 도구야 껄껄! 파이썬에서는 def 키워드를 사용해서 만든다무새."

입력(Input)과 출력(Output)

  • 입력 파라미터 (매개변수): 함수가 일하기 위해 외부에서 받아오는 재료야. 괄호 () 안에 변수 이름으로 적어줘!
  • 출력 파라미터 (리턴값): 함수가 일을 다 끝내고 우리에게 돌려주는 결과물이지. return 키워드를 써서 내보낸다무새!

타입 지정 (Type Hinting)

요즘 파이썬에서는 입력과 출력의 형태(타입)를 미리 적어주는(Type Hint) 것이 대세야! 코드를 읽기도 편해지고, AI 자동완성이나 에러 방지에도 최고라구.
입력은 변수: 타입으로 적고, 리턴 타입은 -> 타입 형식으로 표시해!

함수 예시 (Python)

두 숫자를 받아서 더한 뒤 돌려주는 깔끔한 파이썬 함수 예시야:

def add_numbers(a: int, b: int) -> int:
    """두 정수를 입력받아 합을 리턴하는 함수"""
    result = a + b
    return result

# 함수 사용해보기
my_sum = add_numbers(10, 20)
print(f"두 숫자의 합은 {my_sum} 이다무새!")

파이썬 내장함수 (Built-in Functions)

파이썬이 기본적으로 제공해주는 아주 유용한 함수들이야. 별도로 만들 필요 없이 바로 가져다 쓰면 된다무새!

내장함수 설명 사용 예시
print() 데이터를 화면에 출력 print("소성로 온도 정상")
len() 데이터의 길이나 개수를 반환 len(sensor_data_list)
type() 데이터의 자료형(타입)을 확인 type(temperature)
sum() 리스트 내 모든 숫자의 합을 계산 sum([10.5, 11.2, 9.8])
max() / min() 최댓값 또는 최솟값을 찾음 max(pressure_values)

포스코퓨처엠 실무: AI와 자동화에서 왜 쓸까?

  • 센서 데이터 일괄 전처리: 양극재 소성로에서 1초마다 들어오는 수십만 개의 온도/압력 센서 데이터를 정제할 때, def clean_sensor_data() 함수 하나만 잘 만들어두면 새로운 설비 데이터가 들어와도 자동으로 이상치를 걸러낼 수 있다무새!
  • 코드 재사용으로 공정 검사 효율화: 음극재 표면 결함을 찾는 비전(Vision) AI 모델을 돌릴 때, 이미지 크기를 조절하고 정규화하는 코드를 함수로 묶어두면 수십 대의 검사 장비에서 똑같이 함수 한 번 호출로 뚝딱 해결된다구! (퇴근이 빨라진다무새 🚀)
