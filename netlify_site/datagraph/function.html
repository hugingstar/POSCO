🦜 파이썬 함수 (Function)

기본 개념

"함수는 자주 쓰는 코드를 하나의 상자에 담아두고 필요할 때마다 꺼내 쓰는 마법 같은 도구야 껄껄! 파이썬에서는 def 키워드를 사용해서 만든다무새."

입력(Input)과 출력(Output)

  • 입력 파라미터 (매개변수): 함수가 일하기 위해 외부에서 받아오는 재료야. 괄호 () 안에 변수 이름으로 적어줘!
  • 출력 파라미터 (리턴값): 함수가 일을 다 끝내고 우리에게 돌려주는 결과물이지. return 키워드를 써서 내보낸다무새!

타입 지정 (Type Hinting)

요즘 파이썬에서는 입력과 출력의 형태(타입)를 미리 적어주는(Type Hint) 것이 대세야! 코드를 읽기도 편해지고, AI 자동완성이나 에러 방지에도 최고라구.
입력은 변수: 타입으로 적고, 리턴 타입은 -> 타입 형식으로 표시해!

함수 예시 (Python)

두 숫자를 받아서 더한 뒤 돌려주는 깔끔한 파이썬 함수 예시야:

def add_numbers(a: int, b: int) -> int:
    """두 정수를 입력받아 합을 리턴하는 함수"""
    result = a + b
    return result

# 함수 사용해보기
my_sum = add_numbers(10, 20)
print(f"두 숫자의 합은 {my_sum} 이다무새!")

파이썬 내장함수 (Built-in Functions)

파이썬이 기본적으로 제공해주는 아주 유용한 함수들이야. 별도로 만들 필요 없이 바로 가져다 쓰면 된다무새!

내장함수 설명 사용 예시
print() 데이터를 화면에 출력 print("소성로 온도 정상")
len() 데이터의 길이나 개수를 반환 len(sensor_data_list)
type() 데이터의 자료형(타입)을 확인 type(temperature)
sum() 리스트 내 모든 숫자의 합을 계산 sum([10.5, 11.2, 9.8])
max() / min() 최댓값 또는 최솟값을 찾음 max(pressure_values)

포스코퓨처엠 실무: 각 부서별 파이썬 함수 활용 사례

포스코퓨처엠의 다양한 부서에서 파이썬 함수 하나로 어떻게 업무를 자동화하고 혁신(DX)하는지 살펴보자무새!

  • [안전보건기획그룹 / 포항노재기술안전섹션] 헬스케어 & 유해가스 자동 모니터링: 작업장 내 실시간 유해가스 농도나 스마트 워치 바이오 데이터를 체크하는 def check_safety_alert(sensor_data) 함수를 만들어두면, 위험 수치 도달 시 즉시 사이렌을 울려 안전사고를 완벽히 예방할 수 있어!
  • [실리콘음극재개발그룹 / FullCell평가섹션] R&D 데이터 일괄 분석: 수백 번씩 반복되는 배터리 충·방전(Full Cell) 사이클 테스트 결과를 분석할 때, 데이터 전처리와 성능 저하 곡선(Degradation Curve)을 그리는 과정을 함수 하나로 묶어두면 연구원들의 엑셀 작업 시간이 획기적으로 줄어든다구!

  • [인사문화그룹 / 내화물마케팅그룹] 부서별 데이터 취합 및 대시보드 자동화: 수천 명의 임직원 교육 이수율이나, 글로벌 내화물 고객사별 판매 실적 데이터를 함수에 넣기만 하면 대시보드 업데이트용 통계가 1초 만에 완성!
  • [DX추진반 / 디지털혁신그룹 / 기술기획그룹] 전사적 RPA(업무 자동화) 표준화: 각 부서에서 반복적으로 수행하는 엑셀 취합이나 보고서 작성 업무를 파이썬 함수로 규격화하여 전사 배포함으로써, 포스코퓨처엠의 수작업 제로(0)화를 리딩하고 있어 🚀
