🦜 파이썬 함수 (Function)

1. 기본 개념

"함수는 자주 쓰는 코드를 하나의 상자에 담아두고 필요할 때마다 꺼내 쓰는 도구입니다! 파이썬에서는 def 키워드를 사용해서 만듭니다."

2. 입력(Input)과 출력(Output)

  • 입력 파라미터 (매개변수): 함수가 일하기 위해 외부에서 받아오는 재료입니다. 괄호 () 안에 변수 이름으로 적어주세요.
  • 출력 파라미터 (리턴값): 함수가 일을 다 끝내고 우리에게 돌려주는 결과물입니다. return 키워드를 써서 내보냅니다.

3. 타입 지정 (Type Hinting)

요즘 파이썬에서는 입력과 출력의 형태(타입)를 미리 적어주는(Type Hint) 것이 권장됩니다! 코드를 읽기도 편해지고, AI 자동완성이나 에러 방지에도 매우 유용합니다.
입력은 변수: 타입으로 적고, 리턴 타입은 -> 타입 형식으로 표시합니다.

4. 함수 예시 (Python)

두 숫자를 받아서 더한 뒤 돌려주는 파이썬 함수 예시입니다:

def add_numbers(a: int, b: int) -> int:
    """두 정수를 입력받아 합을 리턴하는 함수"""
    result = a + b
    return result

# 함수 사용해보기
my_sum = add_numbers(10, 20)
print(f"두 숫자의 합은 {my_sum} 입니다!")

5. 파이썬 내장함수 (Built-in Functions)

파이썬이 기본적으로 제공해주는 아주 유용한 함수들입니다. 별도로 만들 필요 없이 바로 가져다 쓰시면 됩니다.

내장함수 설명 사용 예시
print() 데이터를 화면에 출력 print("소성로 온도 정상")
len() 데이터의 길이나 개수를 반환 len(sensor_data_list)
type() 데이터의 자료형(타입)을 확인 type(temperature)
sum() 리스트 내 모든 숫자의 합을 계산 sum([10.5, 11.2, 9.8])
max() / min() 최댓값 또는 최솟값을 찾음 max(pressure_values)
round() 소수점 반올림 round(3.141592, 2) -> 3.14
💡 AI 모델링 최적화 팁: round() 내장함수로 연산 자원 절약하기!
AI 모델을 학습시키거나 대용량 센서 데이터를 전처리할 때, 소수점 아래 10자리까지 내려가는 세밀한 데이터(예: 24.51239845)는 메모리와 연산 속도를 크게 저하시킵니다. 데이터 입력 전에 round() 함수를 이용해 필요한 자릿수(예: round(value, 3))까지만 남기고 반올림해주면, 불필요한 연산 오버헤드를 막고 AI 학습 속도를 획기적으로 올릴 수 있습니다!

5-1. 파이썬 기본 자료구조

함수의 매개변수나 반환값으로 여러 개의 데이터를 넘겨줄 때, 파이썬에서 제공하는 기본 자료구조를 활용하면 데이터를 아주 깔끔하게 관리할 수 있습니다.

자료구조 기호 특징 사용 예시
List (리스트) [ ] 순서가 있고, 수정이 가능한 데이터 집합 ["양극재", "음극재", "전구체"]
Tuple (튜플) ( ) 순서가 있지만, 수정이 불가능한 데이터 집합 (읽기 전용) ("위도", "경도")
Dictionary (딕셔너리) { } 키(Key)와 값(Value) 쌍으로 이루어진 데이터 집합 {"온도": 25.5, "압력": 1.2}
Set (세트) { } 순서가 없고, 중복을 허용하지 않는 데이터 집합 {1, 2, 2, 3} -> {1, 2, 3}

6. 포스코퓨처엠 실무: 부서별 파이썬 함수 활용 사례

파이썬의 가장 큰 장점은 반복되는 코드를 함수로 묶어 자동화할 수 있다는 것입니다. 포스코퓨처엠 실무에서 어떻게 활용되는지 살펴볼까요?

  • [인사문화그룹] 데이터 취합 함수화: 수천 명의 임직원 교육 이수율, 근태 데이터 등 반복적으로 취합해야 하는 인사 데이터를 def aggregate_hr_data(raw_data) 형태의 함수로 만들어 두면, 클릭 한 번으로 대시보드 통계가 1초 만에 완성됩니다.
  • [내화물마케팅그룹] 판매 실적 통계 자동화: 글로벌 고객사별 내화물 판매 실적 및 환율 변동에 따른 이익률 계산 과정을 함수로 규격화해두면, 매달 실적 보고서를 작성하는 시간을 획기적으로 줄이고 데이터 오류를 방지할 수 있습니다.
