JSON

기본 개념

JSON(JavaScript Object Notation)은 키(Key)와 값(Value) 쌍으로 이루어진 경량의 데이터 교환 표준 포맷입니다. 파이썬의 딕셔너리(Dictionary)와 구조가 호환되어 다루기 쉽습니다.

AI 모델 및 자동화에서 사용하는 이유

  • API 통신 표준: OpenAI, HuggingFace 등 외부 AI API에 요청을 보내거나 응답을 받을 때 전 세계 표준 언어로서 직렬화(Serialization)에 사용됩니다.
  • 설정(Config) 파일 관리: 딥러닝 모델의 복잡한 하이퍼파라미터(학습률, 배치 크기, 에포크 등) 환경 설정을 저장하고 다른 환경으로 이식할 때 가장 널리 쓰이는 형식입니다.
  • 비정형 데이터 구조화: 계층적이고 중첩된 데이터를 직관적으로 표현할 수 있어, 다양한 형태의 데이터를 수집하고 파싱하는 크롤링/자동화 작업에 필수적입니다.
