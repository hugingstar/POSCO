🦜 JSON 알아보기

기본 개념

"JSON은 키(Key)와 값(Value)이 단짝 친구로 묶여있는 아주 가벼운 데이터 포맷이야! 파이썬의 딕셔너리(Dictionary)랑 생긴 게 거의 똑같아서 다루기 엄청 편할 거다무새 껄껄!"

AI랑 자동화에서 왜 쓸까?

  • API 통신 표준: OpenAI(ChatGPT)나 허깅페이스 같은 외부 똑똑이 AI들이랑 대화할 때 쓰는 전 세계 공통어라구! 데이터 주고받을 땐 무조건 이거야!
  • 설정(Config) 파일 관리: 학습률, 배치 크기 같은 복잡한 딥러닝 설정들을 텍스트 파일로 예쁘게 저장하고, 다른 컴퓨터로 옮겨서 불러올 때 가장 많이 쓰는 깔끔한 방식이다무새.
  • 비정형 데이터 구조화: 리스트나 다른 객체가 막 뒤섞여 있는 복잡한 정보도 예쁘고 직관적으로 정리해 줘서, 크롤링 자동화할 때 없으면 안 된다구 껄껄!
