🦜 집합 (Set) 알아보기

기본 개념

"집합은 순서도 없고, 중복도 절대 허락하지 않는 아주 까다롭고 콧대 높은 친구야 껄껄! 중괄호 {}나 set()으로 만든다무새."

AI랑 자동화에서 왜 쓸까?

  • 초고속 중복 제거: 수만 개의 데이터에서 겹치는 URL이나 단어들을 코드 딱 한 줄로 완벽하고 제일 빠르게 싹! 날려버릴 수 있다구!
  • 빠른 검색 (O(1) 속도): 속이 마법의 해시 테이블로 되어있어서, 특정 단어가 안에 있는지 찾을 때 리스트보다 눈 빠지게 빠르다무새. (AI 자연어 처리할 때 단어 사전 만들면 진짜 날아다녀!)
  • 데이터 교차 검증: 두 데이터의 공통점(교집합)이나 다른 점(차집합)을 찾을 때 복잡한 for문 없이 벤다이어그램 그리듯 뚝딱 계산해 준다 껄껄!
